Google Sheets Connection

Responses are sent to a Google Sheet via a deployed Apps Script.

Paste the deployed URL of your Google Apps Script here. All form submissions will POST to this endpoint.

Google Maps (Location Fields)

Required only if your forms include a Location field.

Create a key at console.cloud.google.com → APIs & Services → Credentials. Enable the Maps JavaScript API and Places API.

Setup Guide

First time? Follow these steps to connect Google Sheets.

  1. Go to Google Sheets and create a new spreadsheet. Name it something like "Form Responses".
  2. Open Extensions → Apps Script from the menu bar.
  3. Delete any existing code and paste in the script below.
  4. Click Save, then Deploy → New deployment.
  5. Set type to Web app. Set "Execute as" to Me and "Who has access" to Anyone.
  6. Click Deploy and authorize the permissions.
  7. Copy the Web app URL and paste it in the field above.
